# Demo Recording Script

This script is for recording a 60-90 second demo video to accompany the grant application.

## Setup

- Use a real Android phone (preferably a budget device: low-cost/budget range).
- Install the app via APK or open the PWA in Chrome.
- Enable airplane mode before starting the recording.
- Use a screen recorder (built-in on Android 11+).

## Recording sequence

### Scene 1: Context (5 seconds)
Show the phone home screen with airplane mode icon visible in the status bar.
Voiceover: "This phone has no internet connection."

### Scene 2: Launch (5 seconds)
Tap the OpenRights Assistant icon.
Voiceover: "OpenRights Assistant runs entirely on this device."

### Scene 3: First question (15 seconds)
Type: "What is the minimum wage?"
Tap Search.
Show the results with source citations.
Voiceover: "It searches official U.S. labor law passages stored locally and shows the exact text with a source link."

### Scene 4: Second question (15 seconds)
Tap "Debt collection" chip or type: "Can a debt collector call me at work?"
Show results.
Voiceover: "Users can ask about consumer rights, workplace safety, discrimination, or financial protection."

### Scene 5: Source verification (10 seconds)
Scroll to show the source URL on a result.
Voiceover: "Every answer shows where it came from. This is not legal advice, it is cited legal information."

### Scene 6: Offline proof (10 seconds)
Pull down the notification shade to show airplane mode is still on.
Voiceover: "Still offline. No data left the phone."

### Scene 7: Closing (10 seconds)
Show the app info or settings screen with install size.
Voiceover: "The entire app with index is under 5 megabytes. It runs on budget phones with no server cost."

## Tips

- Keep the phone in portrait mode.
- Use a clean home screen (remove personal widgets).
- Record at 1080p or higher.
- Speak slowly and clearly.
- If using a voiceover, record it separately for better audio quality.
- Total video length: aim for 60-90 seconds. Grant reviewers watch many applications.
